每個市場逐項評分 0-5 分：市場焦點、消息品質、市場觀點、技術結構為加分項（滿分 20 分），事件風險為扣分項（風險越高扣越多）。系統會自動排出「今日市場觀察優先順序」。16-20 分為優先觀察，10-15 分為次要觀察，9 分以下暫時放掉。

財經日曆（事件風險參考）

點按鈕在瀏覽器開啟 XM 官網財經日曆，查看近期經濟事件，幫助判斷事件風險這一項該打幾分。

即時報價查詢（參考用）

輸入商品代碼後點「查詢報價」。報價僅供評分參考，非即時成交價，實際下單請以 XM 平台報價為準。查詢紀錄會保留在下方，不會被新查詢覆蓋。

策略指標分析（參考用）

上方輸入框請填「商品代碼」（不是指標名稱），選好週期跟想查的指標後點「查詢指標」。勾選越多指標，一次查詢消耗的免費額度越多。同一個商品重新查詢會自動取代舊結果，不同商品各自保留，每筆結果也可以按「✕」手動關閉。

尚無市場資料，輸入市場名稱後點「＋ 新增市場」開始評分。
此評分法不是交易訊號，也不是獲利保證；它只是幫助把市場選擇從感覺，轉換成可討論、可重複的流程。
資料僅儲存在目前瀏覽器內（重新整理仍會保留，但不會同步到其他裝置或帳號）。

市場選擇五濾網評分系統｜新手填寫指南

不需要每一項都找到 Trading Central 的畫面佐證才能打分，憑當下看盤的直覺判斷也完全可以——評分表的重點是把「感覺」轉換成「數字」，方便討論跟比較，不是要你做學術研究。

建議填寫順序：市場焦點 → 消息品質 → 市場觀點 → 技術結構 → 事件風險

① 市場焦點（對應 TC Market Buzz）

先問自己：今天市場正在看誰？這個商品熱不熱門？

去哪裡看：Market Buzz 分頁的新聞提及次數或熱度儀表板；沒有工具在手邊，就回想今天新聞、社群有沒有一直提到它。

0完全沒人討論，翻遍新聞也找不到相關消息
1幾乎沒熱度，偶爾才看到一則相關新聞
2略有關注，零星幾則新聞或討論
3有一定關注，新聞量算平均水準
4頗受矚目，新聞量明顯比平常多
5明顯熱門，整天新聞都圍繞著它，儀表板標示「熱點」

② 消息品質（對應 TC Newsdesk）

先問自己：這個市場為什麼被關注？是有明確原因，還是只是雜訊？

去哪裡看：Newsdesk 或財經新聞版面，看最近幾則新聞是不是圍繞同一個主題。

0完全零散，看不出主題，也沒有明確消息面
1消息零散，新聞之間關聯性很低
2略有題材但不集中，隱約看得出方向但不強烈
3有題材但不夠集中，主題浮現但仍混雜雜訊
4題材漸明確，大多數新聞圍繞同一主軸
5題材明確，幾乎所有新聞都指向同一個清楚原因

③ 市場觀點（對應 Crowd Insight）

先問自己：市場主流看法是偏多還是偏空？看法會不會太一致、太擁擠？

去哪裡看：Crowd Insight 多空比例，或觀察社群、聊天室裡大家的方向感。

0情緒極度混亂或過熱，多空比例接近一面倒（如 90%/10%）
1情緒混亂或過熱，市場看法很極端
2觀點分歧需留意，看不出明確共識
3有方向但需確認，多數人偏一邊但沒有過度擁擠
4觀點漸清楚，方向感明確且比例還算健康
5觀點清楚且不過度擁擠，方向明確但沒有過熱風險

④ 技術結構（對應 Technical Insight / Views）

先問自己：圖表方向清不清楚？有沒有明確的型態或指標訊號？

去哪裡看：Featured Ideas 的技術型態卡片，看型態＋指標是否雙重確認。

0結構完全混亂，看不出任何型態或方向
1結構混亂，圖表雜訊很多
2訊號零散，隱約有跡象但不成型
3有訊號但不完整，型態出現但缺乏指標確認
4結構漸清楚，有明確型態＋至少一個指標同向確認
5結構清楚，型態、指標、價格位置都指向同一方向

⑤ 事件風險（對應 Economic Insight，扣分項）

先問自己：接下來有沒有重大事件？會不會因為一則消息瞬間翻盤？

去哪裡看：經濟日曆，篩選相關貨幣，看未來 24 小時是否有高影響力事件。

注意：這一項跟其他四項方向相反。分數代表「風險程度」，分數越高風險越大，而且會直接從總分裡扣掉，不是加分。

0暫無高風險事件，近期經濟日曆很乾淨（不扣分）
1風險偏低，事件不多且影響力不大
2有事件但可控（事件還有一段時間，或影響力中等）
3有事件，需留意（今天稍晚有中等重要性數據）
4重大事件太近，風險高（幾小時內有高影響力數據）
5重大事件迫近，風險極高（例如 1 小時內就要公布央行決議，扣 5 分）

總分怎麼解讀

總分 = （市場焦點 + 消息品質 + 市場觀點 + 技術結構）− 事件風險。 前四項滿分共 20 分，事件風險只會往下扣，所以總分上限是 20 分， 如果事件風險偏高，總分也可能扣到很低甚至變成負數，代表這個市場現在風險太大、先避開比較好。

16–20 分今日優先觀察市場
10–15 分次要觀察市場
9 分以下暫時放掉或等待

輔助工具怎麼用（財經日曆／即時報價）

🌐 財經日曆按鈕

點畫面上方「開啟財經日曆網站」，會直接用瀏覽器打開 XM 官網財經日曆頁面， 不需要額外申請帳號，看畫面上近期的經濟事件，幫助判斷「事件風險」這一項該打幾分。

💰 即時報價查詢

輸入商品代碼（例如 EURUSD、XAUUSD）後點「查詢報價」， 可以看到目前價格、漲跌、當日高低點。這個功能第一次使用前要先申請一組免費 API Key： 點「🔗 前往申請 API Key」自動開啟申請頁面，申請完成後回到軟體點「設定 API Key」貼上即可 （詳細申請步驟圖文說明請參考另外附上的「如何申請API金鑰」文件）。 每次查詢的結果會累積保留在下方，不會被新的查詢蓋掉，方便回頭比對。 如果評分表裡已經有好幾個市場，也可以點「🔄 全部重新查詢」一次把所有已列入的商品都重新查一次現價， 系統會自動每隔幾秒查一個，不用擔心超過免費方案的呼叫上限。

🔘 查詢後自動加入市場

即時報價旁邊有一個開關，開啟之後查詢報價成功會自動把該商品加進下方的評分市場列表， 省去手動再打一次名稱的步驟；關閉則只查報價、不影響市場列表。這個開關的開/關狀態會被記住， 下次開啟軟體不用重設。

📈 策略指標分析（RSI／MACD）

輸入商品代碼、選好週期（15分鐘／1小時／4小時／日線）後點「查詢指標」，會顯示 RSI 跟 MACD 的數值跟白話判讀（例如「超買」「超賣」「偏多動能」「偏空動能」），對應評分表裡的「技術結構」 這一項，可以當作參考依據之一，跟自己看圖表的判斷互相對照。跟即時報價共用同一組 Twelve Data API Key，不用另外申請。查不同商品的結果會分別保留在下方； 如果重新查詢同一個商品，舊的那筆結果會自動被最新的取代掉，不會一直往下疊。 每筆查詢結果右上角也有「✕」按鈕，看完可以隨手關掉，保持畫面簡潔。

查完指標後，系統會依你勾選的指標方向是否一致，自動算出一個「技術結構」建議分數顯示在查詢結果下方 （例如勾選的指標全部同向 → 建議 5 分「結構清楚」；方向分歧 → 建議 2 分「訊號零散」）。 這只是建議，不會自動改分數，要按下「套用到⋯的技術結構」按鈕才會真的套用到評分表裡； 如果查詢的商品代碼還沒加進下方評分列表，會提示你先新增市場才能套用。 勾選的指標越多、判斷越準，只選 1 個指標時建議分數會比較保守。

這些都是輔助功能，就算不申請 API Key、完全不用這幾個按鈕，也不影響評分表本身的核心功能。

新手常見疑問

Q：五項一定要每項都找到工具佐證嗎？
不用。找不到資料時，憑當下盤感或經驗直接給分也可以。

Q：卡在某一項找不到資料怎麼辦？
先跳過，把找得到的項目填完，之後有空再補，不用為了湊分數硬找。

Q：這個分數等於保證獲利嗎？
不是。評分表只是幫助排出「今天比較值得觀察」的優先順序，不是交易訊號，也不是獲利保證。

軟體使用說明｜從零開始上手

這份說明是寫給完全沒用過這套軟體的人看的，照著順序看下去，不需要任何背景知識也能學會操作。

這是什麼軟體？

這是一套幫助判斷「今天要優先觀察哪些市場」的評分工具。每個市場（例如黃金、歐元美元）依照五個項目各打 0-5 分， 系統會自動算出總分，總分越高代表越值得優先關注。它不是自動交易軟體，不會幫你下單，也不保證獲利， 純粹是幫助整理思路、方便記錄跟討論的小工具。

第一次打開軟體，跳出「Windows 已保護您的電腦」怎麼辦？

這是正常現象，不是病毒警告。因為這個軟體是新做的、沒有花錢申請微軟的「數位簽章」， Windows 系統看到「來路不明的新程式」就會提醒一下，跟安全性沒有直接關係。處理方式：

1看到藍色視窗寫「Windows 已保護您的電腦」，點左下角的「其他資訊」（藍色底線文字）
2點開後畫面會多一個按鈕，叫「仍要執行」
3點「仍要執行」，軟體就會正常打開

新手第一次使用，照這個順序做

1畫面最下方的輸入框，輸入你想評分的市場名稱（例如 XAUUSD 代表黃金），點「＋ 新增市場」
2畫面上會多出一張這個市場的卡片，五個項目（市場焦點、消息品質、市場觀點、技術結構、事件風險）分別點選 0-5 分
3每個分數按鈕滑鼠停留一下，會顯示這個分數大概代表什麼情況，當作打分參考

6想匯出成 Excel 可以打開的檔案，點「匯出 CSV」

不用。這兩個功能需要另外申請一組免費的 Twelve Data API Key 才能用，如果完全不申請、不設定， 評分表本身的核心功能（新增市場、打分數、匯出 CSV）完全不受影響，一樣可以正常使用。 這兩個是額外的輔助小工具，方便查價格、抓技術指標數字時省去自己開瀏覽器找的時間而已。

常見問題

Q：資料存在哪裡？重開電腦會不會不見？
資料存在這台電腦目前使用的軟體裡，重新整理不會不見，但如果換電腦或重灌系統，資料不會跟著過去。

Q：可以同時開很多市場評分嗎？
可以，市場數量沒有限制，新增幾個都可以同時放在列表裡。

Q：分數打錯了可以改嗎？
可以，直接點其他分數按鈕就會換成新的分數，不用先刪除重新輸入。

Q：想刪掉某一個市場，不是全部清空，怎麼辦？
每張市場卡片右下角有一個「刪除」按鈕，只會刪掉那一個市場。

Q：即時報價／策略指標查詢一直失敗怎麼辦？
先確認有沒有設定 API Key、Key 有沒有貼對；如果都確認過還是不行，把錯誤訊息截圖起來，方便進一步排查問題。
